# 从初剪母版到终审交付：四轮打磨复盘

本案例遵循“先锁死故事与声音母版，再叠加视觉包装，最后只针对看片瑕疵做局部微调”的返修纪律：

```text
初剪与配音合成
  → 音画锁定母版（Content Lock）
  → 叠加透明包装层
  → 原速看片找出具体瑕疵
  → 仅解冻对应层做局部微调（Conform）
  → 对照核验修改项与锁定项
```

## 1. 第一阶段：锁死故事主线与音画母版

初剪定稿母版集中立住了四件事：

- **四集素材只拧成一股绳**：哪怕横跨第 2、3、6、21 四集，全片也只讲透一件事——“死了三年的白月光挽着亲哥回来当准大嫂，嘴上死不认账，身体却在强吻和见他受罚挨打时次次出卖真心”。
- **三处灵魂原声寸步不让**：“大嫂”、“我好想你，日日夜夜地想你，想把你抽筋扒皮，挫骨扬灰”、“有我在，你别怕”三段原声全部保持 `1.0x` 原速原调，旁白一律在演员开口前收声、尾音落定后再接话。
- **避开原片闪白残影**：结合切点检测与亮度排查，在第六集递蜜饯安抚段落前跳过了原片刺眼的曝光叠化，直接从干净稳定的对视反应帧切入。
- **过场从简、戏眼留足**：交代前情的过渡镜剪得干净利落，而洗手台强吻后的怔忡睁眼、飞身挡击后的心疼对视则留足情绪余韵。

对应公开产物：[`clip_plan.json`](clip_plan.json)、[`narration.json`](narration.json)、[`timeline.json`](timeline.json)、[`assembly_qc.json`](assembly_qc.json)。一旦母版锁定，解说词、三处原声、混音电平与主线结构全部冻结，绝不在后续包装环节推倒重来。

## 2. 第二阶段：在锁定母版上做包装减法

母版音画锁死后，进入 Remotion 透明包装层设计。经过原速看片复核，包装没有往画面上堆砌花哨贴纸，而是连做了五步减法：

- **片名去啰嗦**：删掉“短剧推荐 / 60 秒看懂”之类的累赘副标题，只留《这一秒过火》剧名本身。
- **片名让出正片区**：把横排剧名收进画面顶部黑边，绝不压在人物头顶。
- **花字只补潜台词**：四处花字（“旧情难藏 / 克制失守 / 本能不会说谎 / 重逢已迟”）全部挑镜头留白处落位，专门点破人物嘴硬心软的反差，绝不照抄底下的字幕。
- **语音与字幕解耦**：7 段 TTS 各自保持一口气讲完的自然语流，屏幕上的字幕条则按实际落盘音频（placed audio）拆成单行短句。
- **压低字幕底板抢眼度**：把刺眼的纯白字改为柔和的暖灰白，精简描边、阴影与多余图标，让观众视线始终留在演员脸上。

对应公开产物：[`captions.json`](captions.json) 与 [`remotion/`](remotion/)。

## 3. 第三阶段：终审看片后仅解冻尾段画面

带着包装层原速通看成片时，发现后半段婚礼长廊有两处影响连贯性的画面瑕疵：

- **42.08 秒处**：皇冠婚服对视镜头末尾有 `0.64` 秒人为定格，画面像卡了一下。
- **46.24 秒附近**：把原片 `2001–2004` 秒同一条长廊奔跑跟拍镜头的中间一截剪掉了，造成肉眼可见的跳接。

本轮返修严格执行**只解冻画面层**：直接回第 21 集原片去掉定格、补回被剪掉的 3 秒长廊连续跟拍，绝不用叠化或闪白糊弄；与此同时，解说词、原声、音效、字幕切入点、片名与花字全部保持冻结，合成时直接流复制（stream-copy）母版音轨。最终落地的逐段帧映射记录在 [`picture-conform.json`](picture-conform.json) 中。

对应公开产物：[`edit-map.json`](edit-map.json)、[`picture-conform.json`](picture-conform.json)、[`delivery-qc.json`](delivery-qc.json)。

## 4. 返修纪律（REVISION 三件套）

任何一轮看片修改意见，都应当拆成三张明白账，而不是一言不合整片重跑 `CREATE`：

1. **修改清单（`change_set`）**：本轮具体要修哪几秒、解决什么肉眼可见的问题。
2. **锁定清单（`frozen_set`）**：哪些故事线、原声留白、混音电平和字幕排版已经验收通过，本轮严禁改动。
3. **验收方式（`verification`）**：修完后怎么证明“该改的真改好了、不该动的分毫未损”，并按原速通看最终交付文件。

本案例的四轮完整返修账本见 [`revision-log.json`](revision-log.json)，复现操作手册见 [`skill-runbook.md`](skill-runbook.md)。
