# 背景调研指南（可选）

Agent 在开始视频理解**之前**可先做一次轻量背景调研，查清作品名称、角色关系、故事前情或专业概念，写入 `work_dir/background_research.json`。随后的视频理解阶段会自动把这份资料并入 VLM 分析上下文，让模型在看画面时直接叫准人名、带着前情读懂眼神和动作，而不至于把所有角色都记成“黑衣男子”“年轻女子”。**调研并非必经步骤**：当前环境没有搜索工具、处于离线状态或用户没给明确片名时，直接跳过即可，不会阻断后续流程。

## 工具选择

使用当前环境里顺手的任意检索方式即可：

- Codex / Claude 内置的联网搜索或网页浏览工具；
- 用户已配好的浏览器自动化或页面抓取工具；
- 在外部浏览器手动查清后把干货整理进 JSON；
- 直接采用用户口头交代的剧情背景或项目目录内已有的资料文档。

## 通用流程

1. 从 `--context` 参数、源文件名或用户描述里提取片名、角色名等检索词。
2. 每次只搜 1–3 个最核心的事实问题，别在无关考据上耗时。
3. 只记对看片和写解说真有用处的干货：人物关系、故事前提、世界观设定、当前集前情、关键术语解释。
4. 将核实后的结果写入 `work_dir/background_research.json`。
5. 若查不到可靠信息，直接跳过调研并继续视频理解；切勿在理解索引尚未生成前抢跑写稿。

## 按视频类型搜索策略

### 短剧 / 电视剧

| 搜索关键词 | 目标字段 |
|-----------|---------|
| `{作品名} 剧情 介绍 人物` | synopsis, characters |
| `{作品名} 人物 关系` | characters |
| `{作品名} 第{N}集 剧情` | episode_context |

### 电影

| 搜索关键词 | 目标字段 |
|-----------|---------|
| `{电影名} 剧情 简介` | synopsis |
| `{电影名} 影评 解读` | cultural_notes |

### 纪录片 / 科普视频

| 搜索关键词 | 目标字段 |
|-----------|---------|
| `{主题} 背景 知识` | worldbuilding |
| `{核心概念} 解释` | synopsis |
| `{主题} 最新 进展` | cultural_notes |

## 写入格式

写入 `work_dir/background_research.json` 时，只填查实的字段；没查到的字段直接省略，不要填 `null` 或空字符串。

```json
{
  "synopsis": "...",
  "characters": {
    "角色名": "简介或关系"
  },
  "worldbuilding": "...",
  "episode_context": "...",
  "cultural_notes": [
    {"item": "...", "explanation": "..."}
  ]
}
```

## 异常情况处置

| 场景 | 处理 |
|------|------|
| 没有浏览器 / 搜索工具 | 跳过调研，继续视频理解 |
| 搜索无结果 | 换一组关键词重试一次，仍无结果则继续视频理解 |
| 检索结果互相打架 | 只采信用户明确交代的上下文，或画面与 ASR 原声能直接印证的信息 |
| 资料里带了后续剧透 | 仅拿来认准人物关系，除非用户明确要求，否则绝不在解说里提前剧透后文结局 |

**铁律**：背景资料只用来补齐前情上下文，绝不能拿来顶替 `vlm_analysis.json` 与 `asr_result.json` 里的当场画面和原声证据。
