# 平台宣发标题、封面与文案备忘（`promo_copy.json`）

仅在用户要求策划发布标题、封面帧与封面字、平台简介或复核开场钩子时使用本指南；常规解说生产不强制生成宣发文件。

> **文件边界区分**：平台标题、封面字与简介等片外宣发备忘写入 `work_dir/promo_copy.json`（不参与视频画面渲染）。需要烧录进视频画布的眉题栏、人物铭牌、花字与音效请按 `./packaging.md` 写入 `work_dir/packaging_plan.json`，切勿混用同名文件。

## 1. 先定单条成片的核心看点

从**当前成片实际拍到并兑现的内容**（而非整部剧的百科梗概）提炼核心矛盾：谁在什么处境下做了什么选择、当场换来什么后果。动笔写标题前，先确认兑现该看点的成片时间位置与画面依据；同一批不同切片应按各自戏眼区分卖点（身份错位、当场反击、暗中护短、悬疑伏笔等），避免套用同质化“惊天反转”句式。

写作准则：

1. **摆具体处境与动作反差，不堆空泛形容词**：用“葬身火海三年的恋人，挽着亲哥回来让我叫大嫂”“股权签字当天，亲妹越过我全权委托给外人”这类带身份、物件与动作的短句直给冲突，不用“高能预警”“虐恋情深”“命运齿轮转动”等空话。
2. **用身份关系替代陌生人名**：面向未看过原剧的路人观众时，标题与封面字优先写清关系与困局（如“前夫”“未来大嫂”“新任总监”），不堆砌生僻人名与专有设定词，也不提前剧透片内尚未演到的结局。
3. **忠于片内事实尺度**：角色放狠话不等于事情已做成，单方试探不等于双方和解，受挫受伤也不夸大成生死结局。

如需结合外部平台讨论做选题调研：已播剧可检索真实高赞讨论点与常见争议并核对本片能否接住；未播剧直接依据片内人物反差提炼看点。引用外部案例时注明来源链接与日期，查不到确切数据时直接写明“仅依据片内素材推演”。

## 2. 各宣发与画面文字层的分工

| 文字层 | 存放位置 | 职责与边界 |
|---|---|---|
| 发布标题（`titles`） | `promo_copy.json` | 补齐关系前情、争议看点或互动问题；不照抄旁白全文，不编造片内未出现的台词 |
| 封面帧与封面字（`cover`） | `promo_copy.json` | 选定表情或动作最有张力的成片秒数，用简短封面字点出核心矛盾，不与视频内常驻标题逐字重复 |
| 平台简介与话题（`description` / `tags`） | `promo_copy.json` | 简明交代剧名/出处与讨论切口 |
| 画布常驻眉题与花字（`header` / `callouts`） | `packaging_plan.json` | 烧录在成片画布上的常驻标题、人物铭牌与重点花字（规范见 `./packaging.md`） |
| 对白与旁白字幕 | `subtitles.ass` / `.srt` | 忠实呈现听得见的旁白与原声台词，不用花字替代正常字幕 |
