# 背景调研指南（可选）

背景调研可在两个时机进行，结果统一写入 `work_dir/background_research.json`：

1. **开始视频理解**之前**（推荐）**：只要能从源文件名、`--context` 或用户指令中认出作品名称、人物关系、故事前情或专业概念，先写好 `background_research.json` 再继续视频理解。理解阶段会自动把这份资料并入 VLM 分析上下文，让模型在看画面时叫准人名、结合前情读懂眼神和动作，避免把角色笼统记成“黑衣男子”“年轻女子”。
2. **写稿前补充调研**：如果已经跑完视频理解，动笔写稿前发现仅凭现有理解简报仍摸不清作品名称、人物关系或关键设定，也可以补写 `background_research.json`。**在理解完成后新写入的资料不会自动重跑或改写已有 VLM / ASR 产物**，仅作为 `context-only` 的写稿背景；当前镜头里演了什么、说了什么，始终以 `vlm_analysis.json` 与 `asr_result.json` 的时间线证据为准。

**调研并非必经步骤**：当前环境没有搜索工具、处于离线状态或用户没给明确片名时，直接跳过即可，不会阻断后续流程。

## 流程与边界

1. 用当前环境可用的检索方式（内置联网搜索、浏览器、外部查证或项目已有资料文档），从 `--context`、源文件名或用户说明里提取片名、角色名、分集号或专业术语，每次只查 1–3 个核心事实问题。
2. 只记录对看片和写解说直接有用的事实：人物真名与关系、故事前提、世界观设定、当前集前情、关键典故或术语解释。
3. 写入 `work_dir/background_research.json` 时只填查实的字段；未查实的字段直接省略，不要填 `null` 或空字符串：

```json
{
  "synopsis": "...",
  "characters": {
    "角色名": "简介或关系"
  },
  "worldbuilding": "...",
  "episode_context": "...",
  "cultural_notes": [
    {"item": "...", "explanation": "..."}
  ]
}
```

## 异常情况处置

| 场景 | 处理 |
|------|------|
| 没有搜索工具或离线 | 跳过调研：在理解前就继续视频理解；在创作阶段就回到当前创作阶段，先写好 `recap_story_plan.json` 与 `visual_audio_board.json`，再按当前所处的 `full` 或 `cut` 阶段写 `narration.json` 或 `clip_plan.json` |
| 搜索无可靠结果 | 换一组关键词重试一次，仍无结果则跳过调研，按上一条继续流程 |
| 检索结果互相冲突 | 只采信用户明确交代的上下文，或画面与 ASR 原声能直接印证的信息 |
| 资料包含后续剧透 | 仅用于核对人物关系，除非用户明确要求，不在解说中提前透露后文结局 |
