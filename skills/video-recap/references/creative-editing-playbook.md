# 创作剪辑工作法

动手写 `clip_plan.json` 或 `narration.json` 之前，Agent 先把故事主线、选镜逻辑与声画分工拍板落盘。

## 先判断创作控制模式

- **CREATE**：首次创作，尚无既定方向。先摆出至少两个立得住的故事与剪辑方案，比对优劣后再选定一个。
- **DIRECTED**：用户已经指定了结构、镜头、台词或语气。目标是精准落地，别为了展示创意去硬造备选方案。
- **REVISION**：用户看片后提修改意见。最新反馈直接覆盖旧决定；本轮没点名的部分一律锁定不动。

REVISION 模式下先列清“本轮修改项”和“锁死项”：口播腔调、节奏或字幕断行意见写回 `style_card.json`，选镜出入点与声音主导权写回 `visual_audio_board.json`；只有故事主线或核心视角变动时才改 `recap_story_plan.json`。删掉某个镜头或某句词时，同步把计划文件里的旧锚点删干净。每次只提能精确定位到具体节拍（beat）、切点或句子的修法，改完逐项核验“点名要改的真改了，没点名的分毫未动”。

## 决策优先级

两条硬底线永远排在审美前面：

1. **事实有据**：人物身份、关系、前因后果和结局必须有画面、对白、可靠背景资料或用户说明撑腰，绝不凭空脑补。
2. **声音听得清**：关键原声对白不能被拦腰斩成半截，旁白也不能把观众非听不可的那句原话死死盖住。

守住硬底线后，若不同诉求打架，按以下先后顺序取舍：

1. 人物状态与情绪冲击；
2. 故事因果推进；
3. 呼吸与轻重快慢节奏；
4. 视线顺畅与动作连贯；
5. 技术层面的工整对齐。

宁可留一点接点上的毛边，也别为了追求机械工整去砍掉人物变脸、顿住或哽咽的那一秒。

## 五次专业判断

### 1. 导演：先定观众进来体验什么

别急着憋第一句解说词，先想透六个问题：

- **观众承诺**：点开这条片子的人，看完具体能爽在哪儿、揪心在哪儿或看明白什么？
- **主视角（POV）**：全程贴着谁的处境走？谁只是对面的施压者或旁观者？
- **核心悬念**：哪根刺一直扎在观众心里，逼着他看到最后一秒？
- **情绪弧线**：开场是什么气压，经过哪几折，最后落在哪口气上？
- **藏牌与翻牌**：哪条底牌先压住不表，留到哪一拍掀开才最炸？
- **结尾余味**：最后一幕定格时，观众心里留下的是唏嘘、解气还是后背发凉？

CREATE 模式至少拿两个能自圆其说的剪辑方案同台比对，比的是叙事杀伤力而不是换几个形容词——比如“顺着女主的眼睛一步步撞破骗局”对比“开场直接亮出同日改嫁死对头的狠招，再倒推她是怎么被逼到这一步的”。DIRECTED 与 REVISION 模式直接沿用既定主线，不走形式主义发散。计划文件只记拍板结果与核心理由，不贴长篇推导。

### 2. 故事编辑：把流水账筛成有反差的节拍

一拍（beat）不是固定几秒钟、不是场景标题、也不是一段旁白，而是**局势发生的一次肉眼可见的转折**。留下的每一拍，至少要让以下一件事发生实质改变：

- 观众或角色新知道了什么底细；
- 角色眼下最想保住或夺走什么；
- 场上谁压住了谁、谁落了下风；
- 两个人之间是彻底撕破脸还是暗中护短；
- 场面气压从哪一秒开始变味；
- 一旦迈出这一步，退路怎么被堵死、代价翻了几倍。

如果把某一拍抽掉，前因后果、人物立面和情绪劲头半点不损，说明它是过场废戏，直接砍掉。但砍戏不能只留“结果”而砍掉“刺痛人的前提”：角色为什么忍无可忍、为什么偏偏在这一刻翻脸，如果把铺垫全剪光了，就从原片里挑一句最狠的原话或用半句精炼解说把前提铆上，不必搬回冗长的寒暄。开场钩子抛出的悬念必须在正片里兑现，绝不搞“开头惊天大瓜、结尾轻飘飘揭过”的诈骗式留存。

移交剪辑前，把这一拍里绝对不能误删的原片时刻写进 `clip_plan.json.required_evidence`：`nodes` 数组里每项填唯一 `id`、源视频绝对路径 `source`、原片秒数 `start/end`、轨道类型 `track`（`audio` 或 `video`）以及具体内容 `content`（多源素材补上 `source_id`）；`before` 用 `[前提id, 回应id]` 锁死不可颠倒的先后顺序。只锁最核心的那几秒证据，别把整拍全锁死，也别光靠 `reason` 里写一句“保留前提”。剪辑脚本在吸附切点后会自动校验这些锚点，一旦漏掉会直接报错拦回。

### 3. 画面剪辑：选最扎人的瞬间，而不只是搬运事件

逐拍过筛以下问题：

- **入点（IN）**：能不能晚半秒进，直接切在冲突已经摆上台面的那一刻？
- **出点（OUT）**：话音落定或巴掌扇完后，该干脆切走，还是多停半秒看对方脸上的反应？
- **镜头落点**：台词响起时，看放狠话的人更有劲，还是看对面那个人猛然缩紧的瞳孔、攥白的手指更有劲？
- **真性情瞬间**：那半秒停顿、话到嘴边咽回去、手抖了一下、杯子砸碎的脆响，哪一下最能把人物立住？
- **快慢呼吸**：这一拍该像连珠炮一样顶上去，还是该放慢半拍让寒意渗出来？
- **切点干净**：尽量贴着动作收势、原话句尾和自然气口下刀，别拿固定秒数当尺子硬剁。
- **有一分证据说一分话**：拿画面结果当看点时，画面拍到哪一步就说到哪一步（比如镜头只拍到挨了一拳，就别在文案里写成当场昏死或分出胜负）。

`clip_plan.json` 只收最能让观众钻进主视角（POV）里的硬核瞬间，没必要把原片里发生过的每桩事都塞进成片。

剪辑要做到**刀法利落但戏肉完整**：晚进不能把动作起因切没了，早出不能把人物反应切丢了。交代地点和走位的过场镜越短越好；但两人对视、强吻、挨巴掌、听见死讯或沉默僵持的戏眼，一定要舍得多留半秒，让观众把那口气咽下去再切走。只要反打镜头里有变脸、心虚、眼眶发红或恍然大悟，它就是实打实的戏，绝不能因为时长短就当成废镜头删掉。

场景切换的入出点也要讲究章法：

- **晚进场，慎用前置剧透预告**：默认按正序尽量晚进场，砍掉进门走路、寒暄起势，让前 3 秒直接落在冲突触发动作或扎人台词上；只有在正序冲突实在进得太晚时，才允许摘一段 `<= 2.5s` 的冷开场悬念镜，且必须同时满足四点：不铺垫也能看懂、与后文正片不重复同一机位画面、只抛悬念绝不泄露反转结果、硬切回正片时不跳戏。
- **旁白底下禁放“张嘴哑剧”与重复废反应**：旁白压低原声时，若画面停在角色正脸张嘴滔滔不绝，观众会觉得像消音事故；旁白覆盖段优先切听者变脸反应、动作细节、道具特写或稳态环境镜，剔除剧烈晃动镜头，同款点头/呆看反应镜全片不重复超过两次。
- 切入新人物、新场景或情绪骤变的段落时，先给画面留半秒到一秒把人立住，再让旁白开口，别让旁白每次都跟切点抢同一帧。
- 出点优先落在动作做完、表情凝固、台词落音、沉默绷紧或干净硬切之前；片尾最后一拍必须在结局动作或关键原声落定后留出 `1.5–2.5s` 表情/余韵气口，并在跨入下一场戏前干净收尾。
- 严禁在原片自带的叠化、闪白或转场特效正中间下刀。每一次跨镜头切换，至少要靠画面反差、动作顺接、声音接力或时空跨越中的一项推着走。
- 不同场次的镜头只能用来做平行对照或前后呼应，绝不能硬拼成“同一场里你一拳我一脚”的假因果；严禁提前剧透还没发生的结局。

`scene-change score`、逐帧亮度曲线和接点抽帧拼图只是排查工具：重点看每个拼接点前后 0.5–1 秒，揪出闪帧、白闪或半截叠化。修接点时优先往稳定画面里收、完整保留原片转场的一侧、适当向外多留几帧源素材，或者换用相邻的有效镜头补够时长，绝不能为了画面切得齐整而把角色正在说的半句话一刀切断。所有接点修完后必须原速播放肉眼验收，不能看检测分数过关就算完。

遇到短时间内镜头狂闪的段落，先用 ffmpeg 的 scene 滤镜扫出候选时间点：

```bash
ffmpeg -i input.mp4 -vf "select='gt(scene,0.35)',showinfo" -an -f null -
```

滤镜阈值只是用来捞出可疑切点，闪光灯、叠化和大幅度甩镜都可能误报。把捞出来的时间点对回源片区间和拼接边界后，分三类处置：

- **原片切点**：与主线无关的碎镜头，按完整原片镜头整段拿掉；与主线相关但停留太短、看着像闪帧的镜头，顺着原片往前或往后多保留真实源素材，把完整动作、反应或台词包进来，别动不动用定格或慢放去硬凑时长。
- **本次剪辑制造的切点**：优先微调入出点、恢复同一源镜头的连贯运动、把原本相邻的两段重新合拢，或者换一段有叙事作用的过渡画面；能消掉的假切点尽量消掉，叠化、闪白和包装花字不能用来遮掩坏接点。
- **原片有意为之的快切蒙太奇**：只有当每一个短镜头都在给新信息、新动作或节奏爽点，而且原速播放时眼睛看得清、脑子跟得上，才原样保留；否则一律按无关碎镜或过短闪帧清理。

判断切得密不密，不看死板的固定秒数门槛。一个反打镜头留不留，全看它有没有给出新东西——比如眼神心虚、态度松动、突然听懂潜台词，或者动作有了结果——而不是看它够不够某几秒。先找出同一小段时间里连着跳的候选点，再按正常倍速连看几遍，用肉眼判断观众看到的是利落节奏还是刺眼闪烁。

### 4. 声音与旁白：先定谁当家，再写解说词

每一拍动笔前，先在 `visual_audio_board.json` 里拍板这一拍由哪种声音当家（`audio_owner`）：

- `original_dialogue`：角色亲口说的那句狠话、软话或试探本身就是戏眼；
- `action_sound`：耳光声、砸杯子、推门、枪响等动作音响直接砸出冲突；
- `ambience` / `music`：风雨声、宴会喧闹或配乐变化把气氛托起来；
- `silence`：死一般的沉默、倒吸冷气或欲言又止本身就在说话；
- `narration`：单靠画面和原声交代不清前情、利益关系或暗藏的算计，必须由解说点破。

只有当旁白领到了明确任务时才写字。`narration_job` 只能从下面六项里选：

- `context`：补齐画面外至关重要的人物关系、前史或规矩；
- `causal_link`：把剪辑跳过的因果链条铆合起来；
- `foreshadow`：提前埋下一根马上要爆的钉子；
- `interpretation`：顺着画面细节，点破人物口是心非背后的算盘或代价；
- `transition`：带过时间跨越、场地转移或视角切换；
- `none`：画面、原声或沉默已经把戏演满，旁白闭嘴。

所谓“七成解说、三成原声（7:3）”只是新手实在拿不准时的防满铺参考，绝不是考核指标。高能吵架、当众打脸或窒息对视的一拍，哪怕全留原声、一句旁白不写都行；反过来，跨集压缩前情的段落也可以由旁白一口气带过。

#### 写出网感与解说质感的六条铁律

从大量高留存叙事案例中沉淀出的核心经验只有一条：**像一个知根知底的说书人在耳边盯场面，别像写项目总结报告或语文阅读理解答案**。

1. **起手直接摆“具体处境 + 身份/利益反差”**
   - 别写空泛帽子（“这是一个关于爱恨纠葛的故事”“在复杂的局势下”），也别写慢热寒暄或人物简历。第一句就直接交代：**什么场合 + 谁手里干着什么 + 当场撞见什么反差**。
   - 例：`除夕家宴上，她刚做完脊椎手术扶着墙进门，亲妈非但没扶一把，反倒一把扯下她的护腰往祠堂里拽，逼她当众给全族磕头。`
2. **用“手头动作 + 当场后果”彻底清零议论升华腔**
   - 把文稿里的“这意味着……”“这是一场关于……的较量”“让权力与骄傲退场”“完成认知闭环”“内心防线崩塌”“命运的齿轮”彻底清零。写人物狠，就写他怎么撕纸、怎么甩手；写人物痛或心虚，就写他怎么躲眼神、怎么抓空。
   - 例：不要写“生死关头的承诺让权力与骄傲退场，只剩相依为命的执念”，要写“平日一句话定人生死的长公主，此刻死死攥着他的染血衣袖，只求他活着跟自己回家”。
3. **人物点名克制，次要角色用关系锚定**
   - 60 秒以内短片最多点名 **1–2 个核心角色**（首句最多出现 1 个人名并顺手带出身份），其余次要角色一律用关系/职能称呼（如“前女友”“她上司”“太医”），首次提到陌生关系时只用半句顺手点明，不让观众在短片里背人名表。
4. **强视觉必同频，结局必须由画面演完、绝不画蛇添足**
   - 画面一旦出现接吻、扇耳光、下跪、晕倒、亮底牌等强视觉奇观或关键触发动作，必须由保留原声或紧邻旁白正面点破原因，严禁音画各说各话。故事结局必须由画面与关键原声当场演出来；结果落定后直接留白收尾，**严禁在结果演完后再补一句总结升华旁白，也严禁在收束旁白后再拖一句重复同一结果的原声尾巴**。
5. **原声前后的「垫半句、让半句、接半句」**
   - 原声台词出来前，旁白只用完整收口的短句把利害关系垫高（例：“苏曼揣着户口本推开门，屋里传来的却是秦斯礼漫不经心的声音。”）；原声说出“一个小蜜用五年，我早就玩腻了”时，旁白完全让开；原声落音后，下一块旁白直接接结果（“苏曼一句话没吵，收起户口本转头就跟他的死对头领了证，婚礼还定在同一天。”），绝不把原声台词再嚼一遍，也不写破折号或悬半截没说完的引子句。
6. **一口气顺下来的真人口播呼吸与纯器乐配乐**
   - 旁白主导一拍时，按“原本处境 → 突发动作 → 当场后果”写成一个完整长句或两三句咬合紧密的短句，让一次 TTS 自然念完；靠精炼字数贴合画面窗口，不靠高倍速硬塞。若铺外部配乐，只准用纯器乐（零歌词人声），且情绪必须贴合当场戏味（悲恸克制戏不用轻快流行鼓点），原片已有大音量人声插曲时绝不再叠外部配乐。

### 5. 观众复核：站在第一次点进来的观众视角挑刺

初稿写完后，先做三遍抽离测试：

1. **掐掉旁白只看画面和原声**：场上谁跟谁不对付、哪一下翻了脸，光看画面和原声能不能看懂七八成？
2. **闭上眼睛只听声音**：把旁白和原声连起来听，像不像一个会讲故事的人把前因后果娓娓道来，还是像冷冰冰的画面说明书？
3. **首尾对账**：前 5 秒抛出的那个钩子，一路往下推的时候有没有跑偏，到片尾到底兑现了没有？

接着逐拍过筛五个问题：

- 把这一拍直接删掉，故事会断吗？不断就删。
- 把反打的反应镜头拿掉，观众还能看清对方是怎么变脸、怎么心软的吗？
- 这一拍要是闭嘴不念旁白，改放原声对白或两秒沉默，是不是更有杀伤力？
- 底牌早一拍亮出来，还是憋到最后一拍再翻，哪个更让人抓心挠肝？
- 入点能不能再晚半秒、出点能不能再利落一点？

每次复核只盯着最影响成片质感的 1–3 个硬伤下刀，别拿换几个近义词的细枝末节去掩盖结构松散。

到最终交付前，把“观众视角”落成真刀真枪的看片动作：从头到尾原速播放最终成片；逐个切点看前后半秒顺不顺；闭眼通听一遍混音；再单独把前 5 秒、高潮拍和结尾拉出来复核。任何脚本跑分和抽帧截图都只是辅助排查，替代不了肉眼看片和亲耳听音。

## Agent 创作产物

## 内容质量基线

前六条在送 TTS 配音前逐拍核对，没达标就先改方案或改稿；第七条在成片渲染出炉后、正式交付前执行：

1. **承诺兑现**：开头抛出的核心悬念，到片尾到底给没给准话？
2. **主线清晰**：是不是从头到尾紧贴一个主视角和一条核心矛盾往前推？
3. **拍拍有变**：留下的每一拍，是不是都让知情范围、强弱态势、人物关系或风险代价往前进了一步？
4. **有人物劲头**：全片有没有保住至少一两个“光靠文字简介绝对替代不了”的眼神、停顿或动作反应？
5. **声画各司其职**：每一拍到底是画面、原声、沉默还是旁白当家，分工清不清楚？
6. **句句有增量**：旁白是不是都在补前情、扣因果、点反差，没有任何一句是在干巴巴复述画面？
7. **真看真听**：最终渲染出的成片文件，有没有原速从头到尾看过、逐个切点盯过、闭上眼纯听过一遍？

这七条基线跟发在抖音、快手还是 YouTube 无关。先把片子本身的戏剧张力和口播质感立住，再去谈标题、封面和平台投放。
