# 创作剪辑工作法

写 `clip_plan.json` 或 `narration.json` 前，先把故事主线、选镜依据与声画分工定妥落盘。

## 先判断创作控制模式

- **CREATE**：从零构建新成片。主线明确时直接写 1 个选定方案即可；仅当源片存在多种剪辑角度（例如顺叙步步揭底对比冷开场倒叙）需要权衡时，比较 2–3 个候选假设再择优。
- **DIRECTED**：用户已指定结构、镜头、台词或语气，按指定方向准确落地，不另编备选方案。
- **REVISION**：用户看片后提出返修意见。最新反馈覆盖旧决定，未点名的部分保持不变。

`REVISION` 模式下先列清“本轮修改项”和“冻结项”：口播文风或字幕断行调整写回 `style_card.json`，选镜出入点与声音主导权写回 `visual_audio_board.json`；只有主视角（POV）或核心节拍变化时才改 `recap_story_plan.json`。删掉某个镜头或某句词时同步清理旧锚点，改完逐条核对修改项已落实、冻结项未受影响。

## 决策优先级

两条事实与听感底线优先于一切修辞：

1. **事实有据**：人物身份、关系、前因后果与结局须有画面、对白、背景资料或用户说明支撑，不凭空编造。
2. **声音清晰**：关键原声对白不半句截断，旁白也不盖住观众必须听清的那句原话。

在此之上，不同诉求冲突时按以下顺序取舍：人物状态与情绪反应 → 因果推进 → 轻重快慢呼吸 → 视线与动作连贯 → 机械工整对齐。宁可让时长略微浮动，也不为了凑整数秒而裁掉人物变脸、顿住或哽咽的那半秒。

## 五项核心判断

### 1. 导演：明确观众看什么

落笔前先定六个问题：

- **观众承诺**：观众点进来看完能看明白什么冲突、获得什么情绪体验？
- **主视角（POV）**：全程贴着谁的处境推进？谁是对立面或旁观者？
- **核心悬念**：哪条疑问牵着观众一直看到结尾？
- **情绪弧线**：开场是什么气氛，经过哪几次转折，最后落在什么余韵上？
- **藏牌与亮牌**：哪条关键信息先压住不表，留到哪一拍揭晓最有分量？
- **结尾余味**：最后一幕定格在什么动作、眼神或原声余音上？

计划文件只记结论与取舍理由，不写长篇推导。

### 2. 故事编辑：用局势变化组织节拍

一拍（beat）是一次**可感知的局势、关系或筹码变化**。留下的每一拍，至少推进以下一项：知情范围变化、角色当前目标变化、强弱态势翻转、人物关系进退、场面气氛转折或风险代价升级。

抽掉某一拍后若因果链与人物状态毫无损失，说明是过场戏，直接删去；但删过场时要保住触发翻脸的前提（可挑一句关键原话或用半句旁白点明起因）。开场抛出的悬念必须在正片兑现，不在开头夸大其词而在结尾落空。

不可误裁的源片时刻可登记进 `clip_plan.json.required_evidence`：`nodes` 填写唯一 `id`、源视频绝对路径 `source`、源片秒数 `start/end`、`track`（`audio` 或 `video`）与 `content`（多源补 `source_id`），`before` 用 `[前提id, 回应id]` 声明先后顺序。只登记核心的几秒证据即可。

### 3. 画面剪辑：选准动作与反应瞬间

逐拍检查入出点与画面取舍：

- **晚进场，按需冷开场**：默认顺时序从冲突触发动作或关键台词切入，省掉进门寒暄。仅当正序冲突出现较晚时前置一段冷开场悬念镜，时长随动作自然收住，做到不靠铺垫也能看懂、不与正片重复同一机位、只留悬念不提前泄露结局。
- **保留反应镜**：台词落音或冲突发生时，对面缩紧的瞳孔、僵住的手或沉默反打往往比说话人正脸更有戏，不因镜头短而误删。
- **旁白底下避开“张嘴消音感”**：旁白压低原声时，优先切听者反应、手部动作、道具特写或稳态画面，避免角色正脸连续张嘴说话却听不见声音；同款点头或发呆反应镜避免反复重用。
- **干净切点与收尾气口**：切入新场景或情绪骤变段时可先给画面留半秒立住人物再进旁白；出点落在动作收势、表情定格或台词落音之后，片尾最后一拍留足余韵气口，不在原片叠化或闪白正中间下刀。
- **有一分画面说一分话**：镜头只拍到挨了一拳，文案就不写成当场昏死；不同场次的镜头只做平行对照或呼应，不硬拼成同场假因果。

遇到画面频繁跳切的段落，先用 ffmpeg 的 scene 滤镜定位候选切点：

```bash
ffmpeg -i input.mp4 -vf "select='gt(scene,0.35)',showinfo" -an -f null -
```

闪光灯、叠化和快速摇镜也可能触发高分，需对回源片区间与拼接边界后分类处理：

- **原片切点**：与主线无关的碎镜头按完整原片镜头整段删除；与主线相关但过短的镜头，顺着原片前后多保留真实源素材，把完整动作、反应或台词包进来，少用定格或慢放硬凑。
- **本次剪辑制造的切点**：微调入出点、恢复同源镜头的连续运动、合并原本相邻的片段，或换用自然过渡镜头；叠化、闪白和包装花字不能用来遮掩坏接点。
- **原片有意的快切蒙太奇**：仅当每个短镜头都提供新信息且原速播放清晰易读时保留，否则按碎镜清理。

### 4. 声音与旁白：先定主导音轨，再动笔写词

动笔前先在 `visual_audio_board.json` 为每拍指定声音主导方（`audio_owner`）：

- `original_dialogue`：角色亲口说的关键台词本身就是戏眼；
- `action_sound`：耳光、摔杯、推门、枪响等动作音响直接推进冲突；
- `ambience` / `music`：环境声或配乐烘托现场气氛；
- `silence`：沉默僵持或欲言又止本身更有张力；
- `narration`：单靠画面与原声交代不清前情、利益关系或潜台词，需由解说补足。

旁白任务（`narration_job`）从六项中选择：`context`（补画面外关系与前情）、`causal_link`（衔接剪辑跨度因果）、`foreshadow`（埋伏笔）、`interpretation`（结合细节揭示动机与代价）、`transition`（交代时空转换）、`none`（不写旁白）。“七成解说、三成原声（7:3）”只是素材缺乏明显声画主次时的粗略参考，并非配额。

#### 口播写作准则

像熟悉来龙去脉的讲述者盯紧场面推进，不写公文汇报或阅读理解式点评：

1. **起手直给“具体处境 + 身份或利益反差”**
   - 不写空泛帽子或人物履历，第一句直接摆出场合、动作与反差。
   - 例：`除夕家宴上，她刚做完脊椎手术扶着墙进门，亲妈非但没扶一把，反倒扯下她的护腰逼她进祠堂磕头。`
2. **用具体动作和当场后果代替抽象总结词**
   - 删掉“这是一场关于……的较量”“让权力与骄傲退场”“完成认知闭环”“命运的齿轮”等套话。
   - 例：不写“生死关头的承诺让权力与骄傲退场”，改写为“平日一句话定人生死的长公主，此刻攥紧他染血的衣袖，只求他活着回家”。
3. **按片长控制人物点名密度**
   - 60 秒内短片点名 1–2 个核心角色即可，其余人物用关系或身份称呼（如“前女友”“她上司”“太医”）；3–10 分钟中长解说随主线推进自然点出关键人物真名与立场。
4. **重要画面必有声画呼应，结局交给画面演完**
   - 出现扇耳光、下跪、亮信物等关键动作时，须由原声或紧邻旁白交代原因。结局由画面与原声当场落定，不在结局演完后再补总结升华旁白，也不在收束旁白后拖一段重复同义的原声尾巴。
5. **原声前后“垫半句、让半句、接半句”**
   - 原声开口前用完整收句垫明利害；原声说话时旁白彻底让开；尾音落定后接半句点明后果，不重复原声台词，也不用破折号悬半截引子。
6. **自然口播长短句与纯器乐配乐**
   - 每块旁白按“处境 → 动作 → 后果”写成连贯句子，靠精炼字数匹配窗口；外部配乐只选无歌词纯器乐，原片已有高音量人声插曲时不再叠外部配乐。

### 5. 观众复核

初稿完成后做三遍自检：

1. **关旁白看画面与原声**：核心冲突与翻脸节点光看画面和原声能否看懂主体脉络？
2. **闭眼纯听音轨**：旁白连同原声听起来是否自然连贯，有无碎句电报腔或突兀抢话？
3. **首尾兑现检查**：开场抛出的悬念推进是否连贯，结尾是否真正落定？

交付前务必原速通看最终渲染出的成片文件，逐个检查拼接点并闭眼通听混音。

```json

  "items": [
```

`cut` 模式第一阶段先填源片时间；剪出 `edited_source.mp4` 后在第二阶段补齐 `output_start/end` 并复核每拍的声音主导方与旁白任务。
