# 长篇写稿：名场面清单、大纲、写稿与通读改稿

## 1. 名场面清单

- 读完全部笔记，先按集列出值得放原声的戏：笑点、交锋、高甜、反转、立住人物的金句、每集收尾那句；每条记起止时间、谁对谁、一句理由，按精彩程度排。
- 清单前几名必须进片，大纲每段至少用上一条；只交代信息的对话（地址、行程、价钱）用旁白带过，不占原声。

## 2. 大纲

- `EDIT_PLAN.md` 先定主视角、贯穿全片的核心悬念，正文分 8–12 段，每段写起因 → 转折 → 结果、用到清单哪几条。
- 开头钩子 20–35 秒：一条因果线（人物处境 → 冲突 → 原声 → 悬念），第一句就是旁白；钩子里出现的身份、处境前面都交代过，悬念落在具体问题上（他会不会答应、她能不能赢），不用「擦出怎样的火花」这类套话；钩子原声不用正文已用的段落，钩子说过的正文开头不再说。

## 3. 写稿

- 正文按原片时间往后讲，不回头、不预告。每句旁白一件事，12–35 字，按停顿加逗号；讲谁、为什么、结果，像说书人，不描述画面，也不复述观众同时看得见、听得见的。
- 只写素材里有的事，动机、因果按台词推，不曲解；人物用名字，第一次出场交代身份；说话人以笔记、转写标的为准，拿不准就不把话安到具体人头上。回忆、梦境要说明。
- 原声段放完整：问要有答，表白要有结果，冲突有回击；开头不是缺上文的回话，结尾话说完。剪掉停顿后一般 8–20 秒，最长约 30 秒；更长就只留改变局面的那几句往来，其余用旁白带过。
- 垫半句、让半句、接半句：原声前一句交代谁对谁、在什么情况下开口，但不说出原声里的话或结果；后一句接住尾音讲反应或后果，不复述。前后句不讲同一件事。1–4 句旁白接一段原声，两者约各半。

## 4. 通读改稿

写完（挑画面改过字的也算）用 `plan.py script` 打出全文，像没看过剧的观众从头读到尾，逐条改：

- 跟得上：每个人第一次出现有身份，原声里提到的人和事前面交代过，每段有结果；删戏后留下的半截（提到却没交代的事）补全或删干净。
- 一句一件事：塞了两件事、中途换主语、念着拗口的拆成两句；句数不必压，片长按内容走。
- 对事实：逐句对笔记，同一物件、设定前后一致。
- 原声：清单前几名都在、没被腰斩；开头不悬空、结尾话说完；前一句没说破，后一句没复述。
- 描述画面的句子（谁低头、转头、望向哪里）改成讲事；全片反复出现的词和句式（如「想起……的回忆」）换说法。
