# 宣发标题、花字与文案返修

用户要求宣发选题、标题/封面/发布稿、花字优化，或把外部模型的文案回填时使用。
只写解说或精修剪点时不增加这一步。

## 先确定这条片卖什么

从当前短片而不是整部剧提炼一个具体观看理由：人物做了什么选择、付出什么代价，
观众将看懂什么或感受到什么。先标出片内兑现的画面/原声位置，再写承诺。
同一批可以分别卖关系、选择、笑点、动作或推理，不把每条都套成反转或复仇。

用户需要案例研究时，按发行状态选来源：

- **已播剧**：看本剧社媒的真实讨论、传播切片与观众关注点，再判断当前短片能否承接。
- **未发布剧**：用剧本特色和片内证据形成受众假设，参考近期成功宣发案例；不假设本剧已有热度。

记录参考物料的发布者、链接、发布日期、采集日期、具体做法及可借部分。
单条播放、整剧热度、话题聚合量分开写；有数字也不等于证明某句标题带来了成绩。
旧研究需要更新时再查证；未查到的效果不补数字，离线方案明确只依据已有材料。

## 给其他模型的任务包

按共同剧情与观看理由分组，让每组有足够上下文，但每条分别交付。直接用短 Markdown
任务包即可，不另造视频时间线。每条提供：

1. **当前版本**：具体工程、对应成片和待渲染修改；有版本号/内容指纹时沿用已有值。
2. **片内内容**：正文结束点、故事起因与回报、当前选镜、原声/解说字幕、时间属于哪版成片。
3. **现有文案**：两行标题、花字及其位置/时间、时空提示；封面和发布稿存在时一并给出。
4. **本轮范围**：允许修改的文字层，以及保留的剪点、字幕、旁白、声音、样式和片尾。
5. **证据缺口**：角色所说与已发生事实的差别、未出现的结果、模糊专名和未核时码。

附一段可直接使用的要求：

> 先解释这条短片为什么值得点开、看完得到什么，再给主推文案；需要备选时按不同观看理由区分，
> 不只替换近义词。两行常驻标题、封面字和发布标题各司其职。花字、时空提示分别列修改；
> 每处给原文、建议、成片位置和片内依据。没有必要就不加花字。只看到工程/字幕时，
> 时间窗是提案，不能声称已看片。若问题只能靠改镜头或声音解决，单列出来，不用加字掩盖。

## 写字时的分工

| 层 | 工作 | 常见修法 |
|---|---|---|
| 常驻标题 | 让陌生观众理解人物处境与本片回报 | 用动作和代价降低人名/术语门槛；不提前宣布未呈现的胜负 |
| 封面字 | 在封面画面上聚焦一个看点 | 不再塞一遍两行标题；文字需与所选封面帧一致 |
| 发布标题 | 补关系、背景或观看邀请 | 不把解说全文搬过来，不冒充角色原话 |
| 花字 | 补必要理解、观察方向或克制的情绪批注 | 不重复对白、不遮关键动作；拥挤时优先撤花字 |
| 时空提示 | 说明当前/往事、地点或画外判断来源 | 跟随画面切换，不跟跨场旁白提前切换 |
| 对白/旁白字幕 | 忠实承载当前可听见的话 | 不属于宣发改字范围，不拿新花字覆盖或替代 |

“却”“不是……而是……”不是禁词；当素材没有需要纠正的预期时，直接写行动和后果。
人物许诺不等于事情已成，单向凝望不等于双方相爱，受伤不等于死亡。
批量检查重复的是观看理由和句式，不把共享镜头但回报不同的片子合并成同题。

## 回填到当前工程

- 先核任务包对应的工程是否仍是本轮采用基础；已有新剪点、换序、换声或待渲染字幕时，
  把建议重新对到新版本，不把旧全文覆盖回去，也不凭文件修改时间决定采用。
- 复制当前工程为新候选，只改本轮采用项；未明确改动的文字、ID、时码、位置和可见性保留。
  **没提到不等于删除**。`notes=[]` 在提案中可表示不新增；回填完整工程时则是清空整轨，
  必须先把“保留/新增/替换/删除”逐项说明白。
- 新增或明确调整花字/时空标的时间时，先对照当前成片的真实画面/台词和帧钟确定出入点；
  CFR核实际帧，VFR用真实PTS找到对应帧号。建议窗只到小数三位时，不当作已核准的帧级锚点。
- 使用已有包装工程字段，不再造一套对白轨。若采用 `theme_foreground_plan`，两行标题写入
  `content.title.primary/secondary`；花字写入 `content.notes`；时空提示写入 `content.markers`，
  时间最终写整数半开区间 `start_frame/end_frame`，不是浮点秒数。
  保留 `base/video/subtitle/profile`。封面与发布稿仍放文案交付，不塞进画面渲染计划。
- 回填后比较修改前后：逐项核已采用的文字变化、未改层一致、时窗未超正文。已有制作工具先做
  计划校验；用户只要改轨时到此停止。渲染后再核新字实际出现、遮挡和阅读负担，不能把
  工程已改叫成片已更新。
