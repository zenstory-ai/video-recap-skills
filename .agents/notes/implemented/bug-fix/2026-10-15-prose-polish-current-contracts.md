# Agent Note: 文档精修对齐当前分析、字幕与采用契约

Status: implemented

## Problem

现行说明中仍有过长的条件句、重复边界和读者不易理解的内部简称。视频理解入口列出了模型与 key，但没有逐项说明音频、抽帧、可选视频片段与汇总文字的外发路径。字幕降级的提示可能让读者误以为原片已有硬字幕也会消失；单技能安装时也无法照搬依赖完整源码目录的字幕测量命令。

## Decision

对当前 40 份技能、参考、双语 README、帮助、测试说明与示例 README，逐文件依次完成语言、冗余、歧义、事实和逻辑五步复核，精修其中 29 份。按现有脚本补齐视频理解的外发内容、目的地与本地读取路径，说明同根安装和源码测量工具的条件，并区分默认烧录降级与仍保留的原片硬字幕。

采用配音按实际 `tempo_policy` 表述，完整声音混音分支单独说明固定原速；实测字幕带默认不透明，比例遮罩仍默认 0.6。原声底轨的样本区间按起止帧各自换算后相减。删除脚本中不存在的 `picture-plan` / `picture_map.json` 指令，保留实际接受的输入别名和旧字段。内容基线前六项在 TTS 前完成，最终看片在渲染后交付前完成。

保留 schema、规则编号、badcase、配对示例、截图引用、远程调用披露和声音权利要求。161 个完整代码块中，160 个逐字保留；一个普通正向 `narration_lint` JSON 示例仅把 `error_count` 从 1 改成 2，与现有两条错误对齐。不改运行脚本、运行依赖、输入支持或套件版本，也不改历史笔记的决定；七个 ClawHub 包按字节变化升补丁号、重锁摘要并同步精确伴随版本。没有经证实可安全删除的现行文件；两份调研指南服务于不同阶段和独立安装技能，均保留。

## Alternatives considered

- 只删词和调整排版：改动容易核对；但外发路径与安装方式的信息缺口会继续误导使用者，因此同时回查脚本并修正文档事实。
- 统一重写所有示例：可以让文章措辞更一致；但示例承担接口与反例的验证作用，因此只改有算术证据的正向计数实错，其余样本保持原样。

## Consequences

说明更短、安装与执行条件更清楚，文档中的能力承诺与当前实现一致。没有改变运行行为；文档涉及的技能包字节变化仍需由发布维护者单独更新 ClawHub 版本与摘要。
