# 生产能力边界与验收原则

通用技能库负责提供稳定、无状态的本地媒体处理工具与清晰的交接契约；创作立意、题材风格、选镜取舍与最终观感由 Agent 和创作者把握，单项目私有配置留在各自工作目录中，不写死进通用核心代码。

## 职责分层

| 层级 | 职责边界 |
|---|---|
| **核心本地工具（`video-recap`）** | 媒体探测（`probe.py`）、带时间戳抽帧拼图与局部裁切（`frames.py`）、本地优先字幕/语音转写（`transcribe.py`）、内容缓存与实测时长配音（`tts.py`）、多源帧精确渲染与响度处理（`render.py`）、7 项物理质检（`check.py`）。 |
| **按需配套工具（`video-recap`）** | Remotion/PNG 包装与防撞音效（`packaging.py`）、剪映/CapCut 草稿导出（`export_jianying.py`）、静态审片页与只读本地审片台（`dashboard.py`）、跨项目素材缓存与版权/音色同意审计（`library.py`）、旁白逐句配镜与长篇 `recap` 段展开（`plan.py`）。均通过 `timeline.json` 单向接入。 |
| **按需拆片参考（`video-reference`）** | 对已有优秀成片做纯本地切点/响度测量与抽帧，由 Agent 整理脱敏的 `REFERENCE_NOTES.md`，仅作参考，不充当生产门禁。 |
| **项目级配置与发布事务** | 具体剧目或频道的字体、BGM、SFX、包装主题、宣发标题文案（`PROMO.md`）以及多平台上传分发，全部留在用户自己的工作目录或素材库中。 |

通用化原则：**只对单一剧目、单一语种或单一平台成立的规则、预设或文案，不写进通用核心代码。**

## 内建后期处理与双层质检

1. **常规后期要求在工具内默认处理**：
   - `tts.py` 按真实音频实测时长并输出 `overflow_s`，**不对配音做变速挤压**；超时优先精简文案或延展画面时长。
   - `render.py` 自动完成 CFR 帧率统一、非连续音频 12ms 微淡入淡出、同源闪避曲线、`-14 LUFS` / `-1.5 dBTP` 响度闭环与画布安全区字幕折行；仅对无法渲染的物理缺失（空视频轨、缺文件、时间窗越出源片时长）报错退出，旁白/原声重叠等非致命时序异常默认记为警告 `warnings[]`（仅显式传 `--strict` 时阻断）。渲染本身不做闪帧修补：短于 0.1 秒的残镜头由 `check.py` 记为 `flash_sliver` 复核提示，`plan.py` 生成原声块时把边缘对齐到附近源切点，避免带进邻镜头的零星帧。
   - `packaging.py` 在生成 PNG 图层前检查同时间窗图层碰撞，并为 `audio.sfx[]` 自动避开旁白和原声对白区间。
2. **物理质检与复核提示分层（`check.json` v1）**：
   - **硬性错误（`fail` → `ok: false`）——仅限确定的物理损坏**：容器损坏或空流、首尾解码报错（`-xerror`）、奇数分辨率/非 `yuv420p`/画布与帧率不匹配、音画或时间线总时长偏差 `> 0.25s`、缺少应有音轨或数字削波（`true_peak > 0 dBTP`）、零或负时长字幕（`end <= start`）。
   - **复核提示（`warn` → `ok: true` + 顶层 `review_hints[]`）——标出重点位置交由编导确认**：黑场过渡、长定格、响度偏低或静音段、切点音频提示（`narration_bed_audio_leak`、`edge_speech_truncation`）、双语重叠字幕或旁白重叠等视语境而定的情况，均附带精确时间戳写入 `review_hints[]`，便于抽帧或试听确认。
   - 每次运行原子覆写 `check.json`，不残留旧结果；**不引入主观审美打分、固定字速阈值或关键词正则拦截**。
3. **成片观感复核**：
   - `check.json` 全绿只说明文件技术规格正常，不代表叙事流畅、构图合适或配乐贴合。交付前需结合 `review_hints`、`frames.py` 成片拼图、审片页（`dashboard.py`）与原速试看完成终审。

## 远程调用与合规底线

- 核心链路默认纯本地运行；仅在显式配置或指定云端 ASR / TTS 引擎时外发音频或旁白文本（详见 `skills/video-recap/references/remote-services.md`）。
- 音色克隆与受版权保护素材须经授权；交付前可用 `library.py audit timeline.json` 核对所有引用资产的版权与授权状态。
