# 生产能力边界与验收原则

通用技能库提供极简、无状态的本地媒体原子工具与清晰交接契约；创作立意、题材风格、选镜取舍与最终看感由 Agent 与创作者掌握，单项目私有配置留在各自工作目录中，绝不写死进仓库核心代码。

## 职责分层

| 层级 | 职责边界 |
|---|---|
| **核心原子工具（`video-recap`）** | 媒体探测（`probe.py`）、带时间戳拼图与局部裁切（`frames.py`）、本地优先字幕/语音转写（`transcribe.py`）、内容缓存与实测时长配音（`tts.py`）、多源帧精确渲染与响度闭环（`render.py`）、7 项物理体检（`check.py`）。 |
| **按需配套叶工具（`video-recap`）** | 数据驱动 JSON 主题包装与防撞音效（`packaging.py`）、剪映/CapCut 草稿导出（`export_jianying.py`）、静态审片页与只读回环工作台（`dashboard.py`）、跨项目素材缓存与版权/音色同意审计（`library.py`）。均通过 `timeline.json` 单向接入。 |
| **按需拆片参考（`video-reference`）** | 对既有优秀成片做纯本地切点/响度实测与抽帧，由 Agent 提炼脱敏 `REFERENCE_NOTES.md`，永不作为生产门禁。 |
| **单项目与操作者事务** | 具体剧目/频道的字体、BGM、SFX、主题 JSON、发布标题文案（`PROMO.md`）以及多平台分发上传，全部留在用户自己的工作目录或素材库中。 |

硬检验标准：**只对单一剧目、单一语种或单一平台成立的规则、预设或文案，绝不写进通用核心代码。**

## 机械正确性与硬/软双层验收

1. **机械正确性内建（不做反复返工的启发式门禁）**：
   - `tts.py` 实测真实音频时长并输出 `overflow_s`，**绝不对人声变速挤压**；超窗时由 Agent 改短文稿或调整画面时长。
   - `render.py` 自动完成 CFR 统一、非连续音频 12ms 微淡入淡出、闪帧防护（`flash_guard`）、同源闪避曲线、`-14 LUFS` / `-1.5 dBTP` 响度闭环与画布安全区字幕换行；仅对 100% 不可渲染的物理缺失（空视频轨、缺文件、时间窗越出源片时长）硬报错，旁白/原声重叠等非致命时序异常默认记为软警告 `warnings[]`（仅显式传 `--strict` 时阻断）。
   - `packaging.py` 在渲染 PNG 图层前检查同时间窗图层碰撞，并对 `audio.sfx[]` 检查是否撞击人声区间。
2. **硬门禁 vs. 软门禁体检（`check.json` v1）**：
   - **硬门禁（`fail` → `ok: false`）——仅限 100% 确定性物理损坏**：容器损坏/空流、首尾解码报错（`-xerror`）、奇数尺寸/非 `yuv420p`/画布与帧率不匹配、音画或时间线总时长偏差 `> 0.25s`、缺少应有音轨或数字削波（`true_peak > 0 dBTP`）、非法零/负时长字幕（`end <= start`）。
   - **软门禁（`warn` → `ok: true` + 顶层 `review_hints[]`）——提醒 Agent 重点查看，绝不粗暴阻断**：黑屏/定格（可能是片头黑卡或静帧留白）、极低响度/死寂空窗、切边音频提醒（`narration_bed_audio_leak`、`edge_speech_truncation`）、双语重叠字幕或旁白重叠等，全部附精确时间戳写入 `review_hints[]` 交由 Agent 看帧/听音判断。
   - 每次运行原子覆写 `check.json`，绝不残留旧 `pass`；**不包含任何主观审美、字速或关键词正则阻断**。
3. **观众视角看片复核（不可替代）**：
   - `check.json` 全绿只证明文件物理健康，不代表故事连贯、构图美观或配乐贴脸。交付前须结合 `review_hints`、`frames.py` 成片拼图、审片页（`dashboard.py`）与原速试看完成冷视角复核。

## 远程调用与合规底线

- 核心链路默认 100% 本地运行；仅在显式配置或指定云端 ASR / TTS 引擎时外发音频或单句文本（详见 `skills/video-recap/references/remote-services.md`）。
- 音色克隆与受版权保护素材须经授权；使用 `library.py audit timeline.json` 可在交付前核对所有引用资产的版权与同意状态。
