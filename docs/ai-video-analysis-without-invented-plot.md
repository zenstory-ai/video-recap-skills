# AI 分析视频总爱乱编剧情怎么办：把亲眼看见的和脑补出来的彻底分开

用大模型看视频写解说时，最容易踩的坑就是模型看见一张截图或半句台词，就开始顺着套路狂编偷窃、背叛、早有预谋的狗血剧本。要根治乱编剧情，核心是把看片记录拆成四层：**画面里看得见的动作与文字、耳朵听见的原话、结合声画能稳妥推出的变化、以及当前素材没交代的未知项**。每一句解读都要能对回具体的时间段；画面只拍到挪了箱子，就不能写成偷了箱子。

## 第一步：把看片记录拆成四层

1. **第一层：画面直接可见的事实**——谁走进了画面、手碰了哪件东西、东西从哪儿挪到了哪儿、画面上的路牌或文件印着什么字。
2. **第二层：耳朵实际听见的对白**——原声说了哪句话；如果只听见画外音、看不清是谁张嘴，如实记为「说话人待确认」。
3. **第三层：有据可查的有限解读**——结合前两层证据能稳稳推出的直接变化（比如箱子从淋雨的桌角挪到了遮雨棚下），推断不能超出画面与台词能证明的范围。
4. **第四层：明确列出的未知项**——人物心里的真实算盘、镜头外有没有私下约定、身份真假、箱子里的东西少没少。只要画面和台词没有明确证据，统一归入「未知」。

记住三条经验：**单张截图只能证明那一帧的姿势，证明不了完整动作；自动语音转写（ASR）能帮你找时间点，但同音错字和串台词必须人工核对；外部百科简介能帮你认出角色名字，但不能替眼前的镜头宣布“他刚刚干了什么”。**

## 随手可用的视频证据核对表

动笔写分镜或解说词前，先拿这张双列表把拿不准的段落过一遍筛子：

| 核对维度 | 填写要求 |
|---|---|
| 本段要搞清的问题 | `<这几十秒里到底是谁对谁干了什么、局面有什么变化？>` |
| 画面亲眼可见事实 | `<人物站位、手头物件状态、动作起止秒数、画面里的真实文字>` |
| 实际听见的对白 | `<原话摘录或听不清的存疑片段；注明是否看清说话人嘴型>` |
| 明确成立的局势变化 | `<知情差、目标、筹码、关系、情绪或风险具体怎么变了>` |
| 有据可查的有限解读 | `<必须同时列出撑起这句话的画面时间点与对白依据>` |
| 证据不够不能乱推的结论 | `<人物内心黑化、偷窃定性、镜头外交易或大结局剧透>` |
| 需要连看核实的区间 | `<动作发生前的起因 → 动作全过程 → 对方反应 → 当场结果>` |
| 最终落笔表述 | `<既有画面感、又紧扣原片事实的两三句地道解说>` |

只要「有据可查的有限解读」那一栏找不出对应的画面秒数或原声台词，立刻把它挪进「证据不够不能乱推的结论」或者直接删掉。

## 实战案例：《雨廊里的红工具箱》

下面用一段原创案例，看看模型是怎么一步步“看图编故事”的，以及怎么用四层证据法把它修回既准确又有现场感的解说。

### 镜头里真实拍到了什么？

社区义务维修活动办在半露天的走廊里。签到桌摆在遮雨棚边缘，桌子后方靠墙还有一排淋不到雨的带顶铁架。

- **0–10 秒**：志愿者梅青拎来一只贴着“放映室转接头”标签的红色工具箱，放在签到桌边角。紧接着雨声变大，雨水顺着棚沿滴在桌角上。
- **10–22 秒**：林陶走进画面，指了指工具箱说：“这边要进水了，我先挪到棚里。”随后双手抱起红箱子，沿着同一条走廊走到遮雨棚深处，放在一张空椅子上。全程镜头没有拍到他开箱，也没交代他是不是器材管理员。
- **22–40 秒**：梅青回到签到桌，环顾四周问：“红箱子呢？”旁边的志愿者朝遮雨棚里努了努嘴。林陶从画外应了一声：“在棚下，没开过。”梅青走到椅子旁，低头看了一眼依然扣紧的箱扣，随后把箱子抱回签到桌后方靠墙的带顶铁架上，转头对林陶说：“下次挪之前叫我一声。”林陶答：“好。”画面定格在干燥铁架上的红箱子。

盘点这段素材的硬证据：桌角飘雨 → 林陶出声说明并把箱子抱到棚下空椅 → 梅青找箱子时林陶立刻回应位置 → 梅青查看时箱扣完好扣紧 → 梅青把箱子挪上靠墙铁架并叮嘱下次先打招呼。至于箱子里的转接头少没少、林陶有没有保管权限、他心里到底怎么想的，镜头一概没交代。

## 把 AI 脑补的抓贼大戏修回真实解说

如果放任模型看两张抽帧就自由发挥，很容易写出这种只图抓眼球却脱离原片的错稿：

> ❌ **AI 脑补越界版**：
> “林陶趁着雨天活动现场混乱，悄悄顺走了装有贵重转接头的红工具箱。等梅青回来发现失窃当场质问，无处藏身的林陶只能拿‘避雨’当借口狡辩，最后在铁证面前乖乖交出赃物并低头认错。”

短短两句话，把当面打过招呼抱去避雨硬写成趁乱偷窃，把从画外立刻回应位置写成被抓包后狡辩，把一句“好”扩写成低头认错。

对照四层证据返修后，既保留了日常沟通里的真实小摩擦，又不冤枉任何一个角色：

> ✅ **紧扣画面的解说改稿**：
> “雨点刚打湿签到桌角，林陶说了声‘这边要进水’，抱起装转接头的红工具箱就往遮雨棚里挪。可梅青一转头发现桌上的箱子没了影，一时没找着，直到林陶在棚下应声、她走过去看清锁扣还严严实实扣着，才把箱子抱回靠墙的防雨铁架上，补了一句规矩：‘下次挪之前叫我一声。’”

不用硬编抓小偷的假冲突：桌角淋雨的急迫、箱子突然不在原位的虚惊一场、再到一句“下次先叫我”的提醒，照样能把几十秒的起承转合讲得清清楚楚。

## 别让单张截图替连续动作下判决

只看林陶双手抱起红箱子迈步的那一帧截图，谁都容易往顺手牵羊上猜。因此核对任何关键动作时，视野都要覆盖**动作前的诱因（桌角进水）→ 动作全过程（同走廊抱到棚下）→ 对方获知信息的反应（梅青找箱、林陶秒回）→ 当场落地的结果（箱扣完好、放上铁架）**。如果原片中间有剪辑切点，要分开记清切点前后各自拍到了什么，别把不同时间、不同地点的两个镜头硬拼成同一个连续动作。

写人物神态也是一样：皱眉、顿住脚步、移开眼神是画面上看得见的动作；而心虚、嫉妒、早有预谋则需要台词和前后行为撑起来。当证据不够时，如实写“梅青顿了一下，顺着手指看向遮雨棚”，永远比硬贴一个心机深沉的标签稳妥。

## 出片前的五步防脑补自检

- [ ] **圈出定性词**：把稿子里所有描述动机、罪名、隐藏身份和最终结局的词圈出来，逐个问自己“这是第几秒哪句台词或哪个画面拍出来的？”
- [ ] **剥离解读看事实**：遮住形容词和心理揣测，只看动作叙述，检查它跟原片画面是不是严丝合缝。
- [ ] **回看完整上下文**：确认没有因为只截了后半截画面，就把前面的关键前提（比如林陶挪箱前明明白白说了声“这边要进水”）给剪丢了。
- [ ] **复核字幕与画面字**：机器转写出来的同音字、人名和画面上的小字是否经过肉眼核对？听不清的词有没有老实标为待确认？
- [ ] **控制背景资料边界**：百科和人物小传只用来认脸和补前情，没有替当前镜头脑补没拍出来的动作。

## 用本仓库的 Skill 怎么跑？

装好本仓库的技能后（见 [`video-recap`](../skills/video-recap/SKILL.md)），可以直接对 Agent 说：“用 `/video-recap` 分析这段视频，先看拼图和转写写出 `MEDIA_NOTES.md`，确认后再剪”（Codex 中写作 `$video-recap`）。技能会调用本地工具 `probe.py`、`frames.py`（生成带时间戳的抽帧拼图与局部特写裁切）和 `transcribe.py`（本地优先读取字幕/Whisper 转写），由宿主多模态 Agent 对照画面与转写记录事实、有限解读与未知项，遇到静音或听不清的片段如实留空，不替空白画面编造台词。

## 常见问题

**视觉模型认出了人物皱眉或冷笑，就能直接写他的真实动机吗？**

不能直接画等号。皱眉、冷笑只能记作当前可见的表情反应；他到底是因为心虚、嫌弃还是身体不舒服，必须结合前后的原声台词和连续行动才能下判断。把“脸上什么表情”和“心里盘算什么”拆开记，才能避免看图乱编故事。
