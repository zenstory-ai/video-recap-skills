# 影视解说文案怎么写：先定主视角与悬念，再按“垫半句、让半句、接半句”交接声画

写影视解说文案最怕一上来就顺着原片时间轴看图说话。好解说一定先想明白观众点进来看什么、全程跟着谁的眼睛走、用哪一个悬念把人从头拽到尾；接着把素材拆成真正发生局势翻转的叙事节点（beat），每一拍先定由画面动作、原声对白、现场声响、沉默还是旁白当家。旁白只在画面交代不清时出手，把前情、因果和潜台词垫到位，到了演员飙戏或重音落下的瞬间立刻闭嘴让位。

## 动笔前先答清六个问题

- **观众承诺**：观众花这一两分钟看完，能吃到什么瓜、弄懂什么反转，或者爽在哪里？
- **主视角（POV）**：全片主要贴着哪个人物的眼睛、处境和抉择走？
- **核心悬念**：哪一个具体问题从第一秒吊到最后一秒？
- **情绪起伏**：观众的情绪从开场的什么状态，一步步推到结尾的什么状态？
- **底牌顺序**：哪张关键信息先藏着不说，留到哪一拍亮出来最能打脸或反转？
- **结尾余味**：悬念揭晓后，最后三秒留给观众什么念想？

把这六条写进故事方案里，再去写开场钩子。无论标题和前 3 秒把胃口吊得多高，后面都必须有实打实的原片画面和原声把账兑现。

## 怎样从原片里挑出有戏的节点（Beat）？

一个节点（beat）不是“换了个房间”，而是人物的处境、筹码或关系发生了肉眼可见的翻转。选段时用“原本什么处境 → 谁干了什么动作 → 当场变成什么局面”来检验：

| 翻转维度 | 选段自检问题 |
|---|---|
| 知情差 | 观众或人物刚刚抓到了什么关键把柄或真相？ |
| 盘算改变 | 人物原本想干什么，被逼之下临时改成了什么主意？ |
| 筹码易手 | 谁拿捏住了对方，谁手里的底牌当场失效？ |
| 关系裂变 | 两人是表面客套暗地捅刀，还是嘴上放狠话身体却护着对方？ |
| 情绪破防 | 哪一个眼神躲闪、停顿或失控动作让场面瞬间变味？ |
| 代价升级 | 这一步迈出去，一旦露馅或失败要付多大的代价？ |

如果删掉某一段画面，前因后果不断、人物劲头不减，那就果断整段砍掉。反过来，哪怕只是两秒钟的欲言又止或眼神闪躲，只要它决定了人物下一秒为什么突然翻脸或心软，就必须留足帧数。

## 解说旁白与原片声音怎么配合？

每一拍动笔前，先在分镜声画板上定死主导音源（`audio_owner`）：原声对白、动作声响、环境/配乐、刻意静默，还是解说旁白。凡是角色当面立规矩、放狠话、拆穿谎言或崩溃认怂的戏眼，必须原速原调留给原声；凡是扇耳光、摔门、砸扳手等靠动静说话的瞬间，旁白提前收声让出冲击力；凡是千言万语全在停顿里的对视，安静本身就是最好的戏。

解说旁白只干五件活：

1. **补齐前情**：交代画面上看不出的身份关系、赌注与旧账；
2. **缝合跳切因果**：把跨场、跨集剪掉的过场用半句话顺过来；
3. **埋下钩子预期**：在人物动手前点出风险，让观众替他捏把汗；
4. **点破潜台词**：结合前后证据拆穿人物的嘴硬或心虚；
5. **跨时空转场**：利落地带过时间推移或地点转换。

画面里已经演得明明白白的动作（比如“他端起茶杯喝了一口”），旁白绝不再念一遍。和原声交接时，牢记**“垫半句、让半句、接半句”**：原声开口前，旁白只把处境和火药味垫到嘴边；原声一开口，旁白立刻闭嘴让演员把狠话砸响；等尾音落定，旁白再顺着对方变脸或沉默补刀点破后果。写词时按一口气能顺下来的完整意思写，屏幕字幕再按阅读宽度拆短，千万别为了凑短字幕把语音切成一惊一乍的电报腔。

## 纸面实战范例：《旧录像里的道歉》

下面用一段未实拍的家庭短片《旧录像里的道歉》，演示怎样在不越过素材证据半步的前提下，把生硬的“看图报告”改造成有呼吸、有钩子的地道解说稿。

### 素材里拍到了什么？

短片讲姐姐回老家帮社区办一场免费缝补课，回家翻找母亲当年示范针法的旧录像带；正在倒带时，弟弟一把按住播放键，冷冷丢下一句：“你找错东西了。”

全片依次出现四样实锤证据：
1. 墙上的社区海报白纸黑字写着“街坊缝补课：全程免费，不收报名费”；
2. 随后放出的旧录像里，母亲一边走线一边叮嘱：“这次课给街坊免费开”；
3. 姐姐在抽屉里翻出弟弟经手的本次课程报名账本，上面记满了已收的报名费；
4. 姐姐拿着账本追问时，弟弟低头承认：“是我收的，没告诉你。”片尾画面停在弟弟关掉手机收款码、姐姐坐下来逐笔核对退款名单。

注意证据边界：单凭开头弟弟按住播放键这一个动作，推不出他为什么要拦；但把海报、母亲遗言、收费账本和当面承认四样证据串起来，前因后果就板上钉钉了。同样，片尾只拍到“关掉收款码、开始核对名单”，解说就只能落脚在“停掉收款、开始一笔笔对账”，绝不能替原片脑补出“所有钱已经全额退清”。

### 对比：生硬报告腔 vs 有质感的声画交接稿

如果按看图说话的报告腔写，出来的稿子既干瘪又抢戏：

> ❌ **生硬报告腔**：
> 她回来帮忙办这次免费缝补课，想找出母亲教针法的旧录像。可这次报名记录里，已经收了钱。新的收费停了。已经收的钱，她开始逐笔核对。

换成“主视角跟着姐姐走 + 垫半句、让半句、接半句”的解说写法，把原声、画面证据和旁白揉成一条顺畅的叙事链：

> ✅ **声画交接定稿**：
>
> **【第 1 拍 · 开场原声钩子】**
> 画面切入弟弟伸手死死按住录像机播放键。
> **原声留白**：「你找错东西了。」（留足姐姐愣住抬头的反应）
>
> **【第 2 拍 · 旁白垫前情 + 母亲原声立规矩】**
> **旁白**（画面扫过墙上的“全程免费”海报与旧录像机）：“姐姐大老远赶回来，本来是想翻出母亲生前教针法的旧带子，帮社区办好这场免费缝补课——可弟弟为什么连带子都不敢让她放？因为带子一转起来，头一句就是母亲当年立下的规矩。”
> **原声留白**（旧电视里母亲抬头微笑）：「这次课给街坊免费开。」
>
> **【第 3 拍 · 账本露馅 + 当面对质原声】**
> **旁白**（画面切姐姐从抽屉底层翻出写满金额的报名表）：“母亲的话还在屋里响着，抽屉底下却翻出了另一本账：这期明明写着分文不取的街坊课，报名表上早就被人一笔笔收了钱。”
> **原声留白**（姐姐把账本拍在桌上）：「这次免费课为什么收钱？」
> **原声留白**（弟弟沉默两秒，垂下眼）：「是我收的，没告诉你。」（留足两人对视的安静停顿）
>
> **【第 4 拍 · 结尾动作兑现】**
> **旁白**（画面切弟弟在手机上关闭收款入口，姐姐拧开笔帽逐行勾选名单）：“话摊开了，弟弟当场关掉了报名收款码；而已经收上来的每一笔街坊钱，姐姐摊开名单，从头一笔一笔核对。”（尾音落下后，留两秒笔尖划过名单的沙沙声收尾）

这段稿子每一句旁白都精准踩在没有关键台词的画面窗口里：母亲立规矩的原话、姐弟俩捅破窗户纸的对质全部原速亮出；旁白只负责把“按住录像机 → 母亲遗言 → 私自收费账本”的因果链拧紧，并在结尾严格停在画面拍到的“关入口、对名单”上，多半句虚构都不添。

## 旁白下结论前，先核对证据底线

| 画面与声音拍到了什么 | 解说可以怎么讲 | 绝不能越界瞎编什么 |
|---|---|---|
| 弟弟一把按住播放键说“你找错东西了” | 点出弟弟拦着不让放带子、心里藏着事 | 不能在开场第 1 秒就断定他是为了贪污报名费 |
| 免费海报 + 母亲原声 + 本期收费账本 + 弟弟亲口承认 | 明确讲出他瞒着姐姐在免费课上私自收钱 | 不能顺嘴扩写成“他前几年一直靠社区课敛财” |
| 弟弟关掉收款入口、姐姐提笔核对退款名单 | 讲清已停掉新收款、开始逐笔核对旧账 | 不能替原片宣布“所有报名费已当场全部退清” |

写每一句解读时，都要在心里指得出它靠的是哪一秒画面或哪一句原话。只要原片没拍出那一层动机或结果，宁可收住结论、留白给画面，也绝不替原片编一段莫须有的内幕。

## 交稿前的三遍活人复核

1. **关掉旁白光看画面**：只留画面和原片人声，故事的起承转合与人物变脸还能看懂吗？
2. **闭上眼睛纯听声音**：不看屏幕只听混音，旁白像不像一个活人在跟你顺畅讲故事？有没有三四个字一蹦的电报腔，或者把原片演员的半句话硬生生盖住？
3. **当回第一次点进来的观众**：前 3 秒抛出的悬念够不够抓人？中间每一拍是不是都在推进这个悬念？到最后一秒把账算清楚了吗？

## 常见翻车写法与急救改法

| 常见翻车写法 | 怎么改出解说质感 |
|---|---|
| 从头到尾念画面（“他走进房间，坐了下来”） | 画面看得见的动作一字不提，旁白只补身份落差、赌注与潜台词 |
| 开头扯嗓子喊“全员恶人”，结尾根本圆不上 | 直接拿素材里真正在抢的利益或真正在瞒的秘密当开场钩子 |
| 为了追求“快节奏”把人物变脸和犹豫全剪光 | 过场走路随便砍，但人物听完狠话后的停顿、眼神闪躲必须留足 |
| 旁白跟演员原声抢麦，两边声音糊成一团 | 按“垫半句、让半句、接半句”提前收声，把名场面彻底让给原声 |
| 句句都是“这不是X，而是Y”“完成了认知闭环” | 删掉公文黑话与假金句，用“手头具体动作 + 当场后果”讲人话 |
| 片尾硬升华一段人生哲理 | 在人物做出最终抉择或留下悬念的动作上干净收尾，余味留给画面 |

## 用本仓库的 Skill 怎么跑？

安装好本仓库的技能后（见 [`video-recap`](../skills/video-recap/SKILL.md)），直接对 Agent 下达自然语言指令即可，例如：“用 `/video-recap` 为这组素材规划解说”（在 Codex 中写作 `$video-recap`）。Agent 会先输出包含观众承诺、主视角和局势翻转节点的 `recap_story_plan.json` 与 `visual_audio_board.json`，严格按素材证据分配原声留白与旁白，绝不替原片捏造没拍出来的动机与结局。

## 常见问题

**影视解说一定要从头到尾铺满旁白吗？**

千万别铺满。原片里极具张力的当面质问、动作撞击声、环境音和窒息的沉默，往往比旁白更有力量。旁白只在需要帮观众补前情、串因果或点破伪装时才开口。

**应该先写解说词，还是先挑镜头？**

先定主视角、核心悬念和每一拍的局势翻转（`recap_story_plan.json`），再去挑镜头（`clip_plan.json`），等初剪成片出来后，最后对着真实的成片画面和停顿窗口写解说词（`narration.json`）。脱离素材闭门造车写出来的稿子，十有八九对不上画面口型与气口；反过来不立主线就顺着原片瞎剪，又只会剪出流水账。
